# Offline evaluation artifacts

`intent-evaluation-v1.json` is a deterministic report generated by:

```powershell
.\scripts\evaluate-intents.ps1
```

The v1 dataset is synthetic and scenario-split. Its results establish a reproducible
engineering baseline only; they do not claim production performance on real guest language.
The report includes the frozen dataset SHA-256, classifier version, per-intent metrics,
confusion matrix, confidence coverage, and accepted-prediction accuracy.
